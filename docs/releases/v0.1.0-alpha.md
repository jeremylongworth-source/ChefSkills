# v0.1.0-alpha Release Notes

Status: release candidate, not released.

## Summary

ChefSkills `v0.1.0-alpha` is the first planned public alpha for a portable culinary Agent Skills framework.

The alpha is intended for review, experimentation, and contribution. It is not a recipe corpus, food-safety certification system, nutrition authority, regulatory advisor, or commercial kitchen compliance tool.

## Included

- Thirteen culinary skills across chef reasoning, ingredients, techniques, substitutions, recipe development, scaling, safety, sauces, baking structure, protein cookery, fermentation, and equipment cookery.
- Two skillsets: `chef` and `recipe-development`.
- A validated culinary router with 89 catalog cases and 44 routing scenarios.
- A culinary state model with 45 examples.
- An evaluation engine with 41 fixtures, 11 regression suites, 9 reports, and 9 scorecards.
- A generated scorecard summary showing 38 evaluated before/after fixtures and no current blockers.
- GitHub Actions validation plus issue and pull request templates for public collaboration.
- Publication audit with no blockers found in tracked files or history.
- Repository settings review plus Dependabot monitoring for GitHub Actions updates.
- Evidence-confidence decision approving current simulated before/after reports for public alpha with explicit caveats.

## Limitations

- Current before/after evaluation outputs are medium-confidence local reviewer simulations, not live captured model runs from a reproducible harness.
- Food-safety guidance is conservative and must not be treated as legal, medical, regulatory, or commercial compliance advice.
- Michelin / fine-dining intelligence and Canadian commercial food-safety tracks are documented future work, not included alpha capabilities.
- Branch protection or ruleset configuration must wait until the repository is public or the GitHub plan changes.
- A live-output evaluation harness remains post-alpha work.
