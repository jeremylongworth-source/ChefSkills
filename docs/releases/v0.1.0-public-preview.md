# v0.1.0 Public Preview Release Notes

This public preview makes ChefSkills available as a GitHub CLI agent-skills source for GitHub Copilot and other supported agent hosts.

Recommended GitHub release state: public preview.

Reason: ChefSkills has completed public-alpha readiness, passes local repository validation, passes GitHub Actions validation, passes `gh skill publish --dry-run`, and has direct `gh skill preview` / `gh skill install` coverage for atomic skill packages. The repository remains pre-v1 because the evaluation evidence is medium-confidence local reviewer simulation evidence and a live-output evaluation harness remains post-alpha work.

## What Is Included

- Thirteen culinary skill packages across chef reasoning, ingredients, techniques, substitutions, recipe development, scaling, safety, sauces, baking structure, protein cookery, fermentation, and equipment cookery.
- Two repository skillsets: `chef` and `recipe-development`.
- A validated culinary router with 89 catalog cases and 44 routing scenarios.
- A culinary state model with 45 examples.
- An evaluation engine with 41 fixtures, 11 regression suites, 9 reports, and 9 scorecards.
- GitHub Actions validation plus issue and pull request templates for public collaboration.
- GitHub Copilot and `gh skill` setup documentation.

## Install Examples

Preview a skill:

```powershell
gh skill preview jeremylongworth-source/ChefSkills chef-core
```

Install a skill for GitHub Copilot at project scope:

```powershell
gh skill install jeremylongworth-source/ChefSkills chef-core
```

Pin the public-preview release when reproducibility matters:

```powershell
gh skill install jeremylongworth-source/ChefSkills chef-core --agent github-copilot --scope project --pin v0.1.0-public-preview
gh skill install jeremylongworth-source/ChefSkills food-safety --agent github-copilot --scope project --pin v0.1.0-public-preview
```

`gh skill install` installs atomic skill folders from `skills/`, not ChefSkills YAML skillsets from `skillsets/`.

## Maturity Boundary

This is not a v1 release. ChefSkills provides culinary decision-support content and must not be treated as legal, medical, regulatory, commercial kitchen, allergen, nutrition, certification, or food-safety compliance advice.

Food safety remains a hard gate. Users must verify current requirements with the applicable authority before acting on jurisdiction-specific, safety-sensitive, vulnerable-diner, preservation, commercial, or regulated material.
