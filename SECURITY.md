# Security

ChefSkills is a culinary skill framework, but safety still matters.

Do not add:

- secrets, tokens, private credentials, or personal data
- unsafe food-handling instructions
- claims that override professional medical advice for allergies, illness, pregnancy, immunocompromised users, or regulated food-service settings
- instructions that encourage serving food when safety is uncertain

Food-safety guidance should distinguish:

- safety requirements
- quality preferences
- uncertainty that requires conservative action
- situations that need local regulatory or professional review

Report security or safety concerns privately to the repository owner.
