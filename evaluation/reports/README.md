# Evaluation Reports

Reports document whether ChefSkills improves outputs on realistic culinary fixtures.

Each report should include:

- decision
- fixtures evaluated
- baseline and skill-enabled evidence links
- scorecard link
- score table
- blockers
- follow-up changes
- validation evidence

Register reports in `evaluation/reports/index.yaml` so validation can confirm referenced fixtures and raw outputs exist.

Each report must also have a JSON scorecard under `evaluation/scorecards/` so trend analysis does not depend on parsing Markdown tables.
