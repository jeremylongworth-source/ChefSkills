# Evaluation Runs

Use this directory for raw before/after outputs that support evaluation reports.

Each run should keep baseline and skill-enabled outputs separate. Reports under `evaluation/reports/` should link to the run files rather than embedding every raw output.

The existing outputs are medium-confidence local reviewer simulations unless a report says otherwise. Use `evaluation/live-runs/` for reproducible live model-output capture packets with prompt hashes, output hashes, model/context notes, reviewer decisions, and rerun instructions.
